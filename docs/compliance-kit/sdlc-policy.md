# Secure SDLC Policy (Template)

## Requirements
1. All changes via pull request with review.
2. CI gates: lint, unit, integration, e2e demo checks.
3. Security controls behind feature flags for progressive rollout.
4. Dependency updates reviewed and tracked.
5. Critical vulnerabilities patched with defined SLA.

## Release Controls
- Migration review for backward compatibility.
- Rollback/hotfix runbook documented.
- Changelog maintained per release.
