# Private Bug Bounty Kickoff Guide

## Program Scope
- API, frontend, authentication, multi-tenant boundaries.
- Exclude social engineering and physical testing.

## Triage Rules
1. Acknowledge report within 2 business days.
2. Classify severity with CVSS + business impact.
3. Assign owner and remediation ETA.

## Disclosure
- Coordinated disclosure only after fix deployment.
- Reward model defined by severity bands.
